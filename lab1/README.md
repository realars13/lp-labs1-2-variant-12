# Лабораторная работа 1

Дисциплина «Методы оптимизации».

Распределение ресурсов ЦОД. Мягкий Арсений Сергеевич. Группа 517, N=14, Y=26, вариант 12.

Из корневой папки комплекта установите зависимости `python -m pip install -r requirements.txt`, затем выполните `python run.py --lab 1`. Требуется Python 3.12.14; инструкции по виртуальному окружению находятся в `../README.md`.

Исходные данные — `data.json`; процедура — `../generate_data.py`, default_rng(10114). Изменять генератор для запуска не требуется. Код модели, решения, проверки и сценариев — `run.py`; общая обвязка HiGHS — `../common.py`.

Читайте `REPORT.md`, затем `STAR_BENCHMARK.md`. В `results/` находятся три плана, таблица расхода ресурсов и теневых цен, малые возмущения, независимые проверки, графики, benchmark и логи. Бенчмарк использует десять задач, по три запуска каждого метода; его данные сохраняются в `benchmark_data.json`.
