# Лабораторная работа 2

Дисциплина «Методы оптимизации».

Доставка воды с потерями. Мягкий Арсений Сергеевич. Группа 517, N=14, Y=26, вариант 12.

Из корневой папки комплекта установите зависимости `python -m pip install -r requirements.txt`, затем выполните `python run.py --lab 2`. Требуется Python 3.12.14; инструкции по виртуальному окружению находятся в `../README.md`.

Исходная сеть — `data.json`; процедура генерации — `../generate_data.py`, default_rng(10114). В коде `run.py` отдельно реализованы построение LP, проверка потоков, жадный алгоритм и сценарии.

Читайте `REPORT.md`. Результаты в `results/`: планы по дугам, балансы вершин, ёмкости и их двойственные оценки, независимая проверка, сравнение с жадным алгоритмом, четыре сценария, схема сети и оригинальные логи. Поток на дуге означает отправляемую воду; доставленный объём умножается на efficiency. Самая загруженная дуга выбирается по максимальному абсолютному потоку базового плана.
