## Воспроизведение

Проверено на Python 3.12.14. Версии библиотек закреплены в [requirements.txt](requirements.txt), сведения о фактическом окружении — в [environment.json](environment.json). Из корня репозитория:

```console
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

Linux или macOS:

```sh
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

Для одной работы используйте `python run.py --lab 1` или `python run.py --lab 2`. Команда `python run.py --regenerate` заново создаёт исходные данные и пересчитывает результаты. Оптимумы и данные воспроизводимы; измеренное время зависит от компьютера.

## Структура

`lab1/` и `lab2/` содержат модели, данные, отчёты и готовые результаты. [run.py](run.py) запускает обе работы; [common.py](common.py) содержит общие функции для HiGHS, CSV, JSON и графиков; [generate_data.py](generate_data.py) формирует данные; [reports.py](reports.py) формирует отчёты. В папках `results/` находятся решения CSV, сценарии, проверки JSON, графики и исходные журналы решателя. Модели и допущения разобраны в отчётах.
